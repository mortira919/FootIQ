# Где мы

Дата среза: 4 октября 2026. Репозиторий: https://github.com/mortira919/FootIQ, ветка `main`.

Стенд крутится локально: `http://127.0.0.1:8000`. База одна, SQLite, файл `backend/data/footiq.sqlite`. Этот файл и `.venv` в git не входят.

## Готово

Игрок входит по имени (`POST /auth/dev-login`). То же имя открывает того же игрока. Новый вход гасит старые токены. Дальше заголовок `Authorization: Bearer`.

На стенде можно выбрать амплуа, решить сцену кликом, закрыть день, пройти раш, отправить видеоразбор, посмотреть историю, радар и топ. Кнопки бьют в живые ручки.

Судья сцены совпадает с клиентскими правилами: поле 68 на 105, атака к меньшему `y`, зеркало, золото, серебро, тень, аут, таймаут. В юнит-тестах ещё нет офсайда, конуса, опеки и «нет адресата».

Рейтинг: Glicko-2, старт 800, RD 350. Первый золотой ответ двигает число сильно, дальше слабее. Запись рейтинга, серии и попытки идёт одной блокировкой, параллельные ответы не затирают друг друга.

Серия растёт от любой задачи дня, один раз за сутки. Сутки считаются в часовом поясе игрока. У текущих записей это `Asia/Almaty`.

Free меняет амплуа раз в 30 дней. PRO включается ручкой `POST /users/me/tier` и живёт 30 дней (`pro_until`). После даты снова Free: замок амплуа возвращается, тренер снова «Ассистент». Пока PRO, видео за день не одно.

Раш: просмотр пачки лимит не тратит. Два сданных спринта в день. Видео на Free: один ответ в день, проверка вместе со вставкой. Повторный разбор после смены роли берёт задачу нового амплуа. Кеш текста привязан к игроку. Правильный вариант видео клиенту не отдаётся.

Есть страна (две буквы), топ общий, региональный и лига. Код лиги сейчас из hex, шесть символов.

Тесты: 70 зелёных, `cd backend && PYTHONPATH=. .venv/bin/python -m unittest discover -s tests`. На Windows без пакета `tzdata` зоны не грузятся, он теперь в `requirements.txt`.

Роли в наших сценах: `gk`, `cb`, `rb/lb`, `dm`, `cm`, `am`, `lm/rm`, `lw/rw`, `st`, `ss`. Десять сцен и один видеоразбор `vid-dm-shadow-1`.

## Чего нет

Apple, Google, RevenueCat, Postgres, Redis, CDN, живая модель для видео. Разбор видео считает рубрика по словам. Покупка PRO на стенде это флаг, не чек.

Репозиторий на GitHub всё ещё публичный. Его стоит закрыть: Settings, внизу, Change visibility.

## Слой /v1

Контракт клиента лежит в `API.md`, код в `backend/app/v1.py`. Стенд работает рядом и отвечает в старом формате.

Сделано по контракту:

- Вход `POST /v1/auth/google` и `/v1/auth/apple`. Сервер проверяет подпись токена по JWKS провайдера, `aud` и `iss`. Ещё есть `refresh`, `logout` и `DELETE /v1/me`. Access живёт час, refresh 30 дней, каждый refresh выдаёт новую пару.
- `GET /v1/me` и `PATCH /v1/me` (`name`, `position`, `region`, `coach`) отдают весь объект `Me`. История попыток: `GET /v1/me/attempts` с `before`.
- `X-Timezone-Offset` в минутах. Сервер хранит его у игрока и считает по нему «сегодня».
- Коды ролей клиента (`fb`, `wm`, `winger`) сервер переводит в наши только на границе API. `sceneId` равен коду роли, у нас на каждую роль одна сцена.
- `POST /v1/modes/{rush|video}/start` списывает попытку на старте. Повтор `attempts/rush` или `attempts/video` с тем же `sessionId` возвращает тот же ответ и второй раз рейтинг не трогает. PRO снимает лимиты.
- Полигон и задача дня идут через `POST /v1/attempts/polygon`. Rush: 3 жизни, после 3,5 минуты сервер отвечает `session_expired`.
- Рейтинги мира и региона, лиги: создать, войти, переименовать, передать права, выйти, удалить. Код лиги собирается из алфавита контракта.
- Ошибки приходят как `{"error": {"code", "message"}}`, у `position_locked` рядом лежит `daysLeft`.

Первый выбор амплуа больше не запускает 30-дневную блокировку, на стенде тоже.

Токены стенда и `/v1` разделены полем `sessions.kind`: токен `dev-login` не открывает `/v1`, токен приложения не открывает ручки стенда (иначе игрок мог бы включить себе PRO через `/users/me/tier`). `dev-login` не входит в игрока приложения. В рейтингах `/v1` только игроки приложения.

Тела запросов `/v1` строгие: `"true"` не превращается в `true`, `"1"` не превращается в число, `NaN` в координатах отклоняется. Время попыток пишется с микросекундами, поэтому история листается без пропусков.

Переменные окружения: `GOOGLE_CLIENT_ID` (web client ID, можно несколько через запятую) и `APPLE_BUNDLE_ID`. Без них вход отвечает `auth_not_configured`. Отзыв Apple при удалении аккаунта требует ещё `APPLE_TEAM_ID`, `APPLE_KEY_ID`, `APPLE_PRIVATE_KEY` (.p8). Без них сервер пишет предупреждение в лог и удаляет игрока без отзыва.

Отступления от контракта:

- ELO считает Glicko-2. `elo` и `positionElo` обновляются отдельно, поэтому `elo` не равен 800 плюс сумма `eloDelta`.
- Видео оценивает рубрика по словам, без LLM. Варианты A/B/C в нашем json заданы долями кадра, сервер переводит их в метры поля.
- `sync-subscription` просто возвращает `Me`. Webhook RevenueCat нет. PRO включается полями `subscription_tier` и `pro_until` в базе.
- Рейтинг собирается из всей таблицы игроков в памяти. На десятках тысяч игроков понадобится окно запросом.

Не сверено: совпадают ли наши 10 сцен с `lib/engine/scenes.dart` клиента. Если в координатах есть разница, исход на сервере и анимация на клиенте разъедутся.
