# Где мы

Дата среза: 5 октября 2026. Репозиторий: https://github.com/mortira919/FootIQ, ветка `main`.

Бэкенд работает на **https://footiq.fly.dev**. Fly.io, приложение `footiq`, регион Frankfurt, одна машина. Без запросов машина засыпает, первый запрос будит её за пару секунд. База SQLite лежит на volume `footiq_data` (1 ГБ, `/data/footiq.sqlite`), Fly снимает с него снапшот каждый день.

Деплой из `backend/`:

```
C:\Users\User\.fly\bin\flyctl.exe deploy --ha=false --remote-only -a footiq
```

Локально стенд открывается на `http://127.0.0.1:8000` (команды в README). Тесты: 70 зелёных, `cd backend && PYTHONPATH=. .venv/bin/python -m unittest discover -s tests`.

## Что работает в /v1

- Вход через Google с проверкой подписи токена по ключам Google, `aud` и `iss`. Ещё есть `refresh`, `logout` и `DELETE /v1/me`. Access живёт час, refresh 30 дней, каждый refresh выдаёт новую пару.
- `GET /v1/me` и `PATCH /v1/me` (`name`, `position`, `region`, `coach`), история `GET /v1/me/attempts` с курсором `before`.
- `X-Timezone-Offset` в минутах: по нему сервер считает «сегодня» для задачи дня, серии и лимитов.
- Коды ролей клиента (`fb`, `wm`, `winger`) сервер переводит в наши (`rb/lb`, `lm/rm`, `lw/rw`) только на границе API. `sceneId` равен коду роли.
- `POST /v1/modes/{rush|video}/start` списывает попытку на старте. Повторная отправка с тем же `sessionId` возвращает тот же ответ без второго начисления.
- Полигон и задача дня (`POST /v1/attempts/polygon`), Rush (3 жизни, 3,5 минуты), видеоразбор с тренером из профиля.
- Рейтинги мира и региона, лиги: создать, войти, переименовать, передать права, выйти, удалить.
- Ошибки приходят как `{"error": {"code", "message"}}`, 500 тоже. Тела запросов проверяются строго.

## Отступления от контракта

- ELO считает Glicko-2, `elo` не равен 800 плюс сумма `eloDelta`.
- Видео оценивает рубрика по ключевым словам, без LLM. Видеоразбор есть только для `dm`.
- `sync-subscription` возвращает `Me` и больше ничего не делает. Webhook RevenueCat нет. PRO включается полями `subscription_tier` и `pro_until` в базе.
- Рейтинг собирается из всей таблицы игроков в памяти. На десятках тысяч игроков понадобится окно запросом.

## Ждём

- **От фронтендера:** Android и iOS OAuth-клиенты в том же проекте Google Cloud, bundle id для Apple, прогон `test/remote_backend_test.dart` против сервера, файлы `lib/engine/scenes.dart` и `test/polygon_test.dart` для сверки сцен.
- **Apple:** нужен bundle id, его надо прописать командой `flyctl secrets set APPLE_BUNDLE_ID=... -a footiq`. Отзыв входа Apple при удалении аккаунта требует ещё `APPLE_TEAM_ID`, `APPLE_KEY_ID`, `APPLE_PRIVATE_KEY` (.p8).
- **Сцены:** совпадение наших 10 сцен с клиентскими не проверено. Если координаты разные, исход на сервере не совпадёт с анимацией.
